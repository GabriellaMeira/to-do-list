# ✅ Lista de Tarefas (To-Do List) – Projeto React

Este projeto é uma **lista de tarefas interativa** feita com React e Vite. Permite adicionar e remover tarefas dinamicamente.

## 🚀 Tecnologias

- React
- Vite
- JavaScript (useState)

## 🧠 Funcionalidades

- ✅ Adicionar nova tarefa
- ❌ Remover tarefas com um clique
- 🔁 Atualização em tempo real

## 📁 Estrutura

src/
├── App.jsx # Componente principal que chama TodoList
├── TodoList.jsx # Componente com a lógica da lista
├── main.jsx # Entrada da aplicação
├── index.css # Estilos opcionais
